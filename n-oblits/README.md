# N-Oblits

Aplicació mòbil (PWA) i escriptori (Mac) per controlar viatges.

## Estructura

- `docs/` — documentació del projecte (context, funcionalitats, model de dades)
- `bd/` — esquema de la base de dades i proves
- `src/` — codi de l'aplicació (mòbil i escriptori)

## Primeres passes

1. Llegir `docs/CONTEXT_viatges.md` per entendre el projecte
2. Consultar `docs/FUNCIONALITATS.md` per veure les funcionalitats planificades
3. Revisar `docs/MODEL_DADES.md` per al model de dades

## Base de dades

- Esquema: `bd/esquema_inicial.sql`
- Prova: `bd/prova_esquema.py` (executa: `python3 bd/prova_esquema.py`)
